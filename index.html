Windows 10 or later · 64-bit · unsigned installer

Install once

The core runtime and media tools are included. No development checkout or terminal setup is required.

Keep your work

Projects and media live outside the installation. Updates and uninstall preserve them.

Stay current

Stable updates download inside Mise when enabled. You choose when to restart, after active work finishes.

Before installing

  • Mise is unsigned. Windows may display a warning. Verify the publisher’s download location and published checksums; never disable Windows security or antivirus.
  • AI generation requires your own provider account or supported agent client. Subscriptions, local models and specialist tools are not included.
  • The update feed is unsigned too. Checksums detect corruption relative to the host, not a compromised publisher or host.
