Privacy and storage

Your projects stay on your computer

Mise stores projects, media and settings outside its installation. Updating or uninstalling the application does not delete that data. Keep independent backups of your original media and project folder.

AI providers and agents

When you request an AI operation, the selected content may be sent to the provider or agent service you choose. This can include prompts, screenplay, images, audio and video. Your account and that service’s terms apply. Mise does not include a provider subscription or bypass your agent client’s permissions.

Updates and this website

This website is hosted by GitHub Pages and reads public release information from GitHub’s API. It includes no analytics or advertising scripts. GitHub necessarily receives ordinary connection information, including your IP address, when you visit or download. Its own privacy policy applies to those requests.

The desktop application can check GitHub Releases for stable updates and download them when enabled. Installation requires your confirmation and an idle workspace. Automatic checks can be disabled. Both the application and its update feed are unsigned; checksum checks do not authenticate a publisher.

Diagnostics and agent setup

There is no automatic analytics or crash upload. Diagnostics are exported locally only when you request them and exclude project content and credentials. Optional agent setup asks before changing client settings and preserves unrelated entries and customized skills. Reload the client after setup or an update.

Third-party software

The installation contains separate Electron, Chromium, Node, FFmpeg, JavaScript and font notices. These components retain their own licenses; no ownership over them is claimed. The separate FFmpeg tools are GPLv3-or-later. Their exact matching source inputs, notices and rebuild instructions accompany each installer in the release assets. Mise’s application source remains private.

The publisher account is omerlefaruk. Downloads are provided through this account’s public release repository; this does not represent a verified Windows publisher signature.
